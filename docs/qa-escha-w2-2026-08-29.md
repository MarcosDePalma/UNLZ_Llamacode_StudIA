## Escha W2 / Qwen3.8

Escha W2 se mantiene como experimento separado. El modelo publicado por
[EschaLabs](https://huggingface.co/EschaLabs/Qwen3.8-27B-Escha-W2) usa el formato
cuantizado propio `escha` y no es un GGUF nativo para llama.cpp. No hay un
GGUF compatible de Escha W2 ni un endpoint SGLang/OpenAI-compatible instalado
en esta PC, por lo que **no se convirtió, registró como modelo local ni se
ejecutó un benchmark Escha**.

El runtime publicado por
[EschaLabs](https://huggingface.co/EschaLabs/escha-runtime-qwen3dense) es un
fork/runtime CUDA de SGLang para Linux x86-64/NVIDIA. Si se dispone luego de
un entorno separado, la campaña deberá medir arranque, tools/reasoning,
TTFT, prefill/decode, contexto efectivo, memoria, estabilidad y calidad
agéntica. Sus parámetros de SGLang no deben transplantarse a llama.cpp. La
campaña Qwen3.8 GGUF existente tampoco se duplicó.
