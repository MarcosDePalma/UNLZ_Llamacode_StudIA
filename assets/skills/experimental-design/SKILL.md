# Diseño experimental

Formulá una hipótesis falsable y definí variable primaria, secundarias, unidad
experimental, controles y factores de confusión. Proponé aleatorización,
cegamiento y replicación cuando correspondan. Justificá tamaño muestral o explicá
qué datos faltan para calcularlo.

Antes de observar resultados, fijá criterios de exclusión, transformaciones,
pruebas estadísticas, tratamiento de datos faltantes y corrección por comparaciones
múltiples. Entregá protocolo paso a paso, tabla de variables, riesgos, plan de
calidad, esquema de datos y criterios de éxito/fracaso.
