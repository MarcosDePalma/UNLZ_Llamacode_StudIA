# Revisión por pares

Resumí primero la contribución con neutralidad. Evaluá novedad, claridad, método,
reproducibilidad, análisis, ética y correspondencia entre evidencia y conclusiones.

Separá observaciones mayores de menores. Cada objeción debe indicar ubicación,
impacto y una acción concreta para resolverla. No pidas experimentos que no sean
necesarios para sostener las conclusiones centrales. Identificá fortalezas además
de debilidades y evitá inferir identidad, intención o prestigio de los autores.
